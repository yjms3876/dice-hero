# サイコロ勇者バトル

ブラウザで遊べるシンプルなサイコロバトルゲームです。

## 概要

- プレーンな `HTML` / `CSS` / `JavaScript` で構成されています。
- `index.html` がメイン画面です。
- ゲームロジックは `script.js` に記述されています。
- スタイルは `styles.css` で定義されています。
- 画像アセットは `assets/` フォルダに格納されています。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「⚔️ 冒険スタート」ボタンを押します。
3. 現在のサイコロの目を見て、次の目が「大きい」か「小さい」かを予想します。
4. 3連続で正解するとボスに勝利し、ゲームクリアです。

## ファイル構成

- `index.html` - ゲームの表示と構造
- `styles.css` - レイアウトとデザイン
- `script.js` - ゲームの状態管理、サイコロ判定、演出
- `assets/` - 画像アセット

## 実行方法

### 方法1: 直接開く

1. `index.html` をダブルクリックして、ブラウザで開きます。

### 方法2: ローカルサーバーを使う

1. ターミナルでプロジェクトのルートに移動します。
2. 次のような簡易サーバーを起動します。

```bash
python3 -m http.server 8000
```

3. ブラウザで `http://localhost:8000` を開きます。
